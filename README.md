# SAPA-RT / SAPA-RW

Digital Community Service untuk pengurus RT dan RW.

SAPA membantu digitalisasi administrasi dan pelayanan lingkungan melalui layanan Managed Service. Satu platform untuk mengelola data warga, keuangan, pengajuan surat, pengaduan, informasi, dan koordinasi wilayah.

**Membangun Lingkungan Digital, Dimulai dari RT.**

## Solusi

- **SAPA-RT** — administrasi dan pelayanan warga dalam satu portal digital
- **SAPA-RW** — koordinasi dan pemantauan pelayanan antar-RT dalam satu wilayah RW

## Fitur utama

- Data warga
- Kas dan iuran
- Pengajuan surat
- Lapor dan aspirasi
- Pengumuman dan agenda
- Dashboard pengurus

## Managed Service

Pengurus fokus melayani warga. Tim SAPA membantu setup, pemeliharaan, backup, dan dukungan teknis sesuai paket.

## Paket

- RT Starter
- RT Professional
- RT Premium
- RW Portal
